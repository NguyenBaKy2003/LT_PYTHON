# 🚀 Dự Án (projects/)

Thư mục này chứa các dự án thực tế từ đơn giản đến phức tạp để giúp bạn áp dụng kiến thức Python vào thực tiễn.

## 🎯 Mục Đích

- 🏗️ Xây dựng các ứng dụng hoàn chỉnh
- 🔨 Áp dụng nhiều khái niệm Python cùng lúc
- 💼 Xây dựng portfolio cho quá trình tìm việc
- 📈 Từ từ tăng mức độ phức tạp

## 📂 Cấu Trúc Dự Án

Mỗi dự án thường có cấu trúc như sau:

```
project_name/
├── README.md              # Mô tả dự án
├── requirements.txt       # Dependencies
├── main.py               # File chính
├── config.py             # Cấu hình
├── src/                  # Source code
│   ├── __init__.py
│   ├── models.py         # Data models
│   ├── utils.py          # Utility functions
│   └── ...
├── tests/                # Unit tests
├── data/                 # Data files
└── docs/                 # Project documentation
```

## 🏆 Các Loại Dự Án

### 🟢 Beginner Projects (Cơ Bản)

**1. Calculator (Máy tính)**
- Tính toán cơ bản (+, -, *, /)
- Menu lựa chọn
- Input validation
- Khái niệm: Functions, loops, conditionals

**2. To-Do List (Danh sách việc cần làm)**
- Thêm/xóa/hiển thị công việc
- Lưu vào file
- Tìm kiếm công việc
- Khái niệm: File I/O, list operations, functions

**3. Number Guessing Game (Trò chơi đoán số)**
- Tính năng random
- Vòng lặp và điều kiện
- Feedback người dùng
- Khái niệm: Loops, conditionals, input validation

**4. Temperature Converter (Chuyển đổi nhiệt độ)**
- Chuyển đổi C ↔ F ↔ K
- Input validation
- Formatting output
- Khái niệm: Functions, string formatting, math

### 🟡 Intermediate Projects (Trung Cấp)

**5. Student Management System (Hệ thống quản lý sinh viên)**
- CRUD operations
- Lưu/load từ file JSON
- Tìm kiếm, sắp xếp
- Classes và OOP cơ bản
- Khái niệm: OOP, file handling, data structures

**6. Personal Finance Tracker (Trình theo dõi tài chính cá nhân)**
- Thêm chi tiêu/thu nhập
- Phân loại giao dịch
- Thống kê và biểu đồ
- Database cơ bản
- Khái niệm: OOP, data analysis, file handling

**7. Web Scraper (Công cụ web scraping)**
- Crawl dữ liệu từ website
- Parse HTML
- Lưu dữ liệu CSV
- Error handling
- Khái niệm: HTTP requests, parsing, exception handling

**8. Weather App (Ứng dụng thời tiết)**
- Call API
- Parse JSON responses
- Display formatted data
- Error handling
- Khái niệm: APIs, HTTP, JSON, error handling

### 🔴 Advanced Projects (Nâng Cao)

**9. Chat Application (Ứng dụng chat)**
- Socket programming
- Multi-threading
- Client-Server architecture
- Database
- Khái niệm: Networking, threading, OOP, databases

**10. Blog Engine (Công cụ blog)**
- Full CRUD functionality
- User authentication
- Database integration
- API endpoints
- Khái niệm: Flask/Django, OOP, databases, authentication

**11. Data Analysis Project (Dự án phân tích dữ liệu)**
- Load và clean data
- Analysis với pandas/numpy
- Visualization
- Statistical analysis
- Khái niệm: Data science, pandas, matplotlib

**12. Machine Learning Project (Dự án học máy)**
- Dataset preparation
- Model training
- Prediction
- Evaluation metrics
- Khái niệm: Scikit-learn, ML basics, statistics

## 🚀 Bắt Đầu Với Dự Án

### Bước 1: Chọn Dự Án
Chọn dự án phù hợp với cấp độ hiện tại của bạn.

### Bước 2: Đọc Hướng Dẫn
```bash
cd projects/project_name
cat README.md
```

### Bước 3: Cài Đặt Dependencies
```bash
pip install -r requirements.txt
```

### Bước 4: Chạy Dự Án
```bash
python main.py
```

### Bước 5: Thực hiện Các Yêu Cầu
- Đọc file README.md của dự án
- Hoàn thành các tính năng cơ bản
- Thêm các tính năng nâng cao (tùy chọn)
- Test kỹ lưỡng

### Bước 6: Tối Ưu Hóa
- Refactor code
- Thêm comments
- Tối ưu hiệu suất
- Chuẩn bị để share

## 💡 Tips Khi Làm Dự Án

### Lập Kế Hoạch
- ✅ Xác định yêu cầu rõ ràng
- ✅ Chia nhỏ thành các phần
- ✅ Vẽ diagram nếu cần

### Viết Code
- ✅ Bắt đầu từ simple, sau đó expand
- ✅ Viết code sạch với naming convention tốt
- ✅ Thêm comments cho logic phức tạp
- ✅ Sử dụng functions để tránh code lặp

### Testing & Debug
- ✅ Test từng phần khi hoàn thành
- ✅ Xử lý edge cases
- ✅ Dùng print/logging để debug
- ✅ Viết unit tests nếu có thể

### Completion
- ✅ Xóa debug code, unused variables
- ✅ Cập nhật documentation
- ✅ Commit to git với message rõ ràng
- ✅ Share trên GitHub/portfolio
