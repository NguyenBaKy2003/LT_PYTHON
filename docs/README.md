# 📚 Tài Liệu Học Tập (docs)

Thư mục này chứa các tài liệu học tập, ghi chú và hướng dẫn về Python và Phát Triển Ứng Dụng.

## 📖 Nội Dung

### Ghi Chú Lý Thuyết
- Các khái niệm cơ bản của Python
- Cú pháp và quy tắc lập trình
- Best practices và mẹo tối ưu hóa

### Hướng Dẫn Chi Tiết
- Hướng dẫn từng chủ đề
- Ví dụ minh họa
- Giải thích chi tiết

### Tài Nguyên Tham Khảo
- Danh sách các hàm và module quan trọng
- Bảng cheat sheet
- Tài liệu tham khảo nhanh

## 🎯 Cách Sử Dụng

1. Bắt đầu với các tài liệu cơ bản
2. Đọc kỹ các ví dụ code
3. Tham khảo trong quá trình làm bài tập
4. Cập nhật với kiến thức mới học được

## 📝 Các File/Chủ Đề

- `basics.md` - Kiến thức cơ bản Python
- `data_types.md` - Các kiểu dữ liệu
- `control_flow.md` - Điều khiển luồng
- `functions.md` - Hàm và modules
- `oop.md` - Lập trình hướng đối tượng
- `file_handling.md` - Xử lý file
- `exception_handling.md` - Xử lý ngoại lệ
- `cheat_sheet.md` - Bảng gợi nhớ nhanh

---

**Ghi chú:** Các tài liệu này được cập nhật thường xuyên khi có kiến thức mới.
