# 📖 Tài Liệu Học Tập (docs/)

Thư mục này chứa các tài liệu, ghi chú và hướng dẫn về Python.

## 📚 Nội Dung

### Cơ Bản Python
- **Giới thiệu Python** - Lịch sử, ứng dụng và tại sao nên học Python
- **Cài đặt và thiết lập** - Hướng dẫn cài đặt Python trên các hệ điều hành
- **Môi trường phát triển** - VS Code, PyCharm, Jupyter Notebook

### Khái Niệm Cơ Bản
- **Biến và kiểu dữ liệu** - int, float, str, bool, list, tuple, dict, set
- **Toán tử** - Toán học, so sánh, logic, gán
- **Chuỗi và xử lý text** - String operations, formatting, methods
- **Số và toán học** - Các hàm toán học, random, decimal

### Điều Khiển Luồng
- **if/else statements** - Điều kiện và lựa chọn
- **Vòng lặp** - for loops, while loops, loop control (break, continue)
- **Comprehensions** - List comprehension, dict comprehension, set comprehension

### Hàm và Module
- **Định nghĩa hàm** - def, parameters, return, default values
- **Scope và lifetime** - Local, global, nonlocal variables
- **Lambda functions** - Anonymous functions
- **Built-in functions** - map, filter, sorted, enumerate, zip
- **Modules và packages** - import, from...import, __name__ == '__main__'

### Xử Lý File
- **Đọc/ghi file** - open(), read(), write(), append()
- **Context managers** - with statement
- **Làm việc với CSV, JSON** - Parsing và tạo file dữ liệu

### Lập Trình Hướng Đối Tượng (OOP)
- **Classes và Objects** - Định nghĩa lớp, tạo instance
- **Attributes và Methods** - Instance variables, class variables, methods
- **Inheritance** - Kế thừa, method override, super()
- **Polymorphism** - Đa hình, duck typing
- **Encapsulation** - Private/protected attributes, properties
- **Special Methods** - __init__, __str__, __repr__, __len__

### Exception Handling
- **Try/except** - Bắt và xử lý ngoại lệ
- **Finally blocks** - Dọn dẹp tài nguyên
- **Custom exceptions** - Tạo ngoại lệ tùy chỉnh

### Chủ Đề Nâng Cao
- **Generators và iterators** - yield, generator expressions
- **Decorators** - Hàm bao bọc, functools
- **Context managers** - __enter__ và __exit__
- **Regular expressions** - Pattern matching, re module

## 🎯 Cách Sử Dụng

1. Đọc các file Markdown để hiểu lý thuyết
2. Xem các ví dụ code trong mỗi file
3. Thực hành các bài tập liên quan trong thư mục `exercises/`
4. Tham khảo các dự án trong `projects/` để thấy áp dụng thực tế

## 📝 Format Tài Liệu

Mỗi file tài liệu thường bao gồm:
- **Giới thiệu** - Khái niệm cơ bản
- **Cú pháp** - Cách viết code
- **Ví dụ** - Code minh họa
- **Bài tập thực hành** - Vấn đề cần giải quyết
- **Lời khuyên** - Best practices
