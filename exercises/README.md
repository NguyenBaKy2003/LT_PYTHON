# 💻 Bài Tập Thực Hành (exercises/)

Thư mục này chứa các bài tập từ cơ bản đến nâng cao để giúp bạn rèn luyện kỹ năng Python.

## 📋 Mục Đích

- 🎯 Cải thiện kỹ năng viết code Python
- 💡 Áp dụng các khái niệm đã học
- 🔧 Phát triển tư duy lập trình
- ✅ Chuẩn bị cho các dự án thực tế

## 🏆 Cấp Độ Bài Tập

### 🟢 Cơ Bản (Beginner)
- Bài tập về biến, kiểu dữ liệu
- Toán tử và biểu thức
- Chuỗi và input/output
- Điều kiện if/else cơ bản
- Vòng lặp cơ bản

**File:** `01_beginner/`

### 🟡 Trung Cấp (Intermediate)
- Hàm và scope
- Danh sách, tuple, dictionary
- Vòng lặp lồng nhau
- Xử lý file
- List comprehension

**File:** `02_intermediate/`

### 🔴 Nâng Cao (Advanced)
- Lập trình hướng đối tượng (OOP)
- Inheritance và Polymorphism
- Exception handling
- Generators và decorators
- Regular expressions
- Working with APIs

**File:** `03_advanced/`

## 📚 Cấu Trúc Bài Tập

Mỗi bài tập thường có cấu trúc:

```
exercise_name/
├── problem.md          # Mô tả bài toán
├── starter_code.py     # Skeleton code
├── solution.py         # Giải pháp tham khảo
└── test.py            # Unit tests (nếu có)
```

## 🚀 Hướng Dẫn Làm Bài

1. **Đọc mô tả bài toán** trong file `problem.md`
2. **Bắt đầu với `starter_code.py`** hoặc viết code từ đầu
3. **Viết solution của bạn** để giải quyết bài toán
4. **Kiểm tra bằng tests** nếu có file `test.py`:
   ```bash
   python test.py
   ```
5. **So sánh với `solution.py`** để học cách tốt hơn
6. **Tìm hiểu thêm** các cách giải khác

## 💡 Tips & Tricks

### Khi Làm Bài Tập:
- ✍️ Đọc kỹ yêu cầu trước khi code
- 🧠 Suy nghĩ về logic trước khi viết code
- 🔍 Kiểm tra edge cases (trường hợp đặc biệt)
- 📝 Thêm comments để giải thích code
- 🧪 Test code với nhiều input khác nhau

### Khi Gặp Khó Khăn:
- 💭 Đọc file mô tả bài toán lại
- 📖 Tham khảo tài liệu trong `docs/`
- 🔍 Tìm bài tập tương tự để học cách làm
- 💬 Thảo luận với bạn học hoặc tìm kiếm trực tuyến
- ⏭️ Nếu quá khó, xem solution tham khảo rồi làm lại
