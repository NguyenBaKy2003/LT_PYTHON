## 🚀 Hướng Dẫn Sử Dụng

1. **Clone repository:**
   ```bash
   git clone https://github.com/NguyenBaKy2003/LT_PYTHON.git
   cd LT_PYTHON
   ```

2. **Chuẩn bị môi trường:**
   ```bash
   python --version  # Kiểm tra phiên bản Python
   ```

3. **Chạy các file Python:**
   ```bash
   python filename.py
   ```
